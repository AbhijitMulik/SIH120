⚙️ SYSTEM CONSTRAINTS (Built-in Safety)
═══════════════════════════════════════════════════════════════════════════════

CSS (Cyclic Steam Stimulation)
  ✓ Steam volume: 60-100 tons
  ✓ Steam pressure: 22-28 bar
  ✓ Injection duration: 18-30 hours
  ✓ Soak time: 24-48 hours

SRP (Sucker Rod Pump)
  ✓ SPM: 3.0-6.5 strokes/minute
  ✓ Stroke: 70-105 inches
  ✓ VFD: 35-55 Hz
  ✓ Rod load: Max 150 tons (CRITICAL)
  ✓ Energy: Max 25 kW
  ✓ Failure risk: Max 60% (with warnings)

All optimization automatically respects these limits.

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Module not found: fastapi"
Solution: pip install -r requirements.txt

Problem: "Port 8000 already in use"
Solution: python main.py --port 8001

Problem: Dashboard doesn't load
Solution: 
  1. Check terminal shows "Uvicorn running"
  2. Try: http://localhost:8000/health
  3. Check browser console (F12) for errors

Problem: Models not training
Solution: python data_generator.py first

Problem: Out of memory
Solution: Generate smaller dataset in data_generator.py
